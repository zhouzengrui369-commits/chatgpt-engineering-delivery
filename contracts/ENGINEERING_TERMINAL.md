# Engineering Delivery Terminal

Use exactly one terminal state.

```text
PROTOCOL_VERSION=DELIVERY-LIFECYCLE-1.0
GOAL_ID=
MILESTONE_ID=
ACTOR_ROLE=ENGINEERING_DELIVERY
ACTOR_CONTEXT_ID=
PRODUCT_CONTRACT_COMMIT=
ENGINEERING_DELIVERY_CONTRACT=
INPUT_STATE=ENGINEERING_DELIVERY_ACTIVE
OUTPUT_STATE=ENGINEERING_READY|ENGINEERING_NOT_READY|BLOCKED_CHANGE_REQUEST_REQUIRED|BLOCKED_EXTERNAL_AUTHORITY|BLOCKED_IDENTITY_DRIFT
CANDIDATE_SHA=
CANDIDATE_TREE=
CANDIDATE_PARENT=
BRANCH_HEAD_MATCH=
PR_HEAD_MATCH=
WORKTREE_CLEAN=
CANDIDATE_MANIFEST_REF=
TECHNICAL_RECEIPT_REF=
ENGINEERING_REQUIRED_EVIDENCE=COMPLETE|INCOMPLETE
OPEN_NON_ENGINEERING_GATES=
UNAPPROVED_DEVIATIONS=
FIRST_BLOCKER=
RECOMMENDED_NEXT_GATE=PRODUCT_GOVERNANCE_CANDIDATE_ADMISSION
FORBIDDEN_CLAIMS_ACKNOWLEDGED=YES
ISSUED_AT=
STOPPED=YES
```

`ENGINEERING_READY` is invalid unless every mandatory identity/artifact field is present and every `engineering_required` item is complete.
